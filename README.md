# Flibusta Reader — Android prototype

Нативный APK для Android 14+ (API 34), телефонов и планшетов. Kotlin + Jetpack Compose, готовый EPUB navigator Readium 3.0.0. FB2 преобразуется в EPUB локально, без сервера и аккаунта. MOBI отложен.

## Проверить приложение

1. Установить `artifacts/FlibustaReader-0.1.0-debug.apk` на Android 14+.
2. Нажать «Демо-книга» для проверки без сети. Это специально написанный демонстрационный текст, не загруженная книга.
3. Кнопка «Aa» открывает размер шрифта, режим страниц/прокрутки и темы. «Главы» — оглавление, «Закладка» — сохранение одной закладки для книги.
4. Закрыть и снова открыть книгу: место чтения сохраняется. На главном экране появляется «Продолжить чтение».
5. «Поиск»: выбрать книги или авторов, ввести запрос, открыть результат, скачать FB2 или EPUB. Нажать «Показать ещё» для следующей страницы.
6. «Добавить файл»: импортировать EPUB, FB2 или архив FB2.ZIP через системный выбор файлов.
7. «Источник»: отдельно задать HTTPS адрес каталога и скачивания. По умолчанию оба — `https://flibusta.is`. `https://flisland.net` можно выбрать для каталога; скачивание остаётся на сервере текстов. Ссылки загрузки берутся из OPDS, приложение не предполагает наличие текстов на flisland.

## Сборка

Необходимы JDK 17 и Android SDK platform 34/build-tools 34.0.0. Версии закреплены для воспроизводимого прототипа с уже установленным SDK; это не выбор последних версий для будущего релиза.

```powershell
./scripts/build.ps1
```

Скрипт создаёт `local.properties` только при его отсутствии, запускает JVM tests, debug APK и Android lint, копирует APK в `artifacts/`. Gradle wrapper включён в репозиторий. Первая сборка требует доступа к Google Maven, Maven Central и Gradle.

## Структура

- `core`: OPDS parser, безопасный XML reader, FB2 → EPUB 3 converter, JVM tests.
- `app/BookRepository.kt`: сеть, ограничение размера 50 МБ, импорт, приватные файлы и индекс библиотеки.
- `app/MainActivity.kt`: библиотека, поиск/навигация, карточка, загрузка, источники.
- `app/ReaderActivity.kt`: Readium, режимы, темы, оглавление и JSON locator.
- `docs/prototype-verification.md`: фактические результаты проверок и ограничения.

Автоматическая проверка в установленном тестовом эмуляторе: `./scripts/smoke-test.ps1 -Serial emulator-5556`. Реальные скриншоты находятся в `artifacts/library-phone.png`, `artifacts/library-tablet.png` и `artifacts/reader-dark.png`.

## Границы прототипа

Загрузки выполняются внутри процесса приложения, без фонового сервиса и автоматического возобновления. После принудительного закрытия незавершённую загрузку нужно повторить. Настройки и библиотека сохраняются локально; MOBI, PDF, синхронизация и аккаунты отсутствуют. Одна закладка на книгу. Пока вместо исходных обложек используются типографические карточки.

FB2: поддержаны обычный текст, заголовки, базовое форматирование, оглавление, JPEG/PNG/GIF/WebP и внутренние ссылки на сноски. Структура представлена одним XHTML файлом; особо большие книги требуют проверки производительности. Внешние ссылки FB2 не переносятся; сложные таблицы, SVG, нестандартная разметка, всплывающие сноски и точное воспроизведение оригинального оформления не заявлены. EPUB с DRM не поддержан.

Дизайн — начальная основа: спокойная типографика, кремовый фон и акцент на библиотеке. До полноценной первой версии остаются улучшение читательского интерфейса, реальные обложки, работа загрузок в фоне, тесты на физических устройствах и расширенные настройки.
