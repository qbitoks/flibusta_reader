# Flibusta Reader — Android 0.2.1

Нативный APK для Android 14+ (API 34), телефонов и планшетов. Kotlin + Jetpack Compose, готовый EPUB navigator Readium 3.0.0. FB2 преобразуется в EPUB локально, без сервера и аккаунта. MOBI отложен.

## Проверить приложение

1. Установить `artifacts/FlibustaReader-0.2.1-debug.apk` поверх предыдущей версии на Android 14+. Не удалять старое приложение: так сохранятся книги и позиции.
2. Нажать «Демо-книга» для проверки без сети. Это специально написанный демонстрационный текст, не загруженная книга.
3. Касание центра текста показывает/скрывает панели. В постраничном режиме края экрана перелистывают. В режиме прокрутки любое короткое касание текста переключает панели; ссылки и выделение обрабатывает Readium.
4. Закрыть и снова открыть книгу: место чтения сохраняется. На главном экране появляется «Продолжить чтение».
5. «Поиск»: выбрать книги или авторов, ввести запрос, открыть результат, скачать FB2 или EPUB. Нажать «Показать ещё» для следующей страницы.
6. «Добавить файл»: импортировать EPUB, FB2 или архив FB2.ZIP через системный выбор файлов.
7. «Источник»: отдельно задать HTTPS адрес каталога и скачивания. По умолчанию оба — `https://flibusta.is`. `https://flisland.net` можно выбрать для каталога; скачивание остаётся на сервере текстов. Ссылки загрузки берутся из OPDS, приложение не предполагает наличие текстов на flisland.

## Новый экран чтения

В режиме чтения системные панели скрыты. Нижняя строка: **время слева, прогресс книги в центре, заряд телефона справа**. Видимая строка занимает 24 dp; прозрачные области касания сохраняют высоту 48 dp. Каждый показатель скрывается нажатием, повторное нажатие в той же области возвращает его. Все три области сохраняют размер и положение даже без подписей. Настройки видимости сохраняются после закрытия приложения. В меню чтения есть «Показать все индикаторы».

Верхняя панель содержит название и автора. Нижняя — текущую главу, оглавление, ползунок позиции, закладку и «Aa». Обе накладываются на текст и не меняют его разбивку. «Aa» открывает нижнюю шторку: белый/сепия/серый/чёрный фон, три системных шрифта с кириллицей, размер текста, межстрочный интервал, поля, прокрутка и яркость. Индивидуальная яркость действует только в окне читалки и не меняет системные настройки телефона.

Закладка одна на книгу; переход к сохранённой закладке доступен в верхнем меню. Время использует формат и часовой пояс устройства, заряд обновляется системными уведомлениями Android. На широком экране колонка текста ограничена 760 dp. Kazimir не включён; «Книжный» использует системный шрифт с засечками.

## Сборка

Необходимы JDK 17 и Android SDK platform 34/build-tools 34.0.0. Версии закреплены для воспроизводимого прототипа с уже установленным SDK; это не выбор последних версий для будущего релиза.

```powershell
./scripts/build.ps1
```

Скрипт создаёт `local.properties` только при его отсутствии, запускает JVM tests, debug APK и Android lint, копирует APK в `artifacts/`. Gradle wrapper включён в репозиторий. Первая сборка требует доступа к Google Maven, Maven Central и Gradle.

## Структура

- `core`: OPDS parser, безопасный XML reader, FB2 → EPUB 3 converter, настройки/касания/геометрия читалки, JVM tests.
- `app/BookRepository.kt`: сеть, ограничение размера 50 МБ, импорт, приватные файлы и индекс библиотеки.
- `app/MainActivity.kt`: библиотека, поиск/навигация, карточка, загрузка, источники.
- `app/ReaderActivity.kt`: Readium, наложение панелей, системные индикаторы, оглавление и JSON locator.
- `app/ReaderChrome.kt`, `app/ReaderPreferences.kt`: оформление, шторка и сохранение настроек.
- `docs/prototype-verification.md`: исторический отчёт 0.1; `docs/reader-ui-verification.md`: проверка 0.2.

Автоматическая проверка в установленном тестовом эмуляторе: `./scripts/smoke-test.ps1 -Serial emulator-5556`. Скрипт проверяет переключение индикаторов, их постоянные области касания, батарею, перезапуск, панели, настройки и перелистывание. Скриншоты новой читалки записываются в `artifacts/reader-0.2-*.png`.

## Границы прототипа

Загрузки выполняются внутри процесса приложения, без фонового сервиса и автоматического возобновления. После принудительного закрытия незавершённую загрузку нужно повторить. Настройки и библиотека сохраняются локально; MOBI, PDF, синхронизация и аккаунты отсутствуют. Одна закладка на книгу. Пока вместо исходных обложек используются типографические карточки.

FB2: поддержаны обычный текст, заголовки, базовое форматирование, оглавление, JPEG/PNG/GIF/WebP и внутренние ссылки на сноски. Структура представлена одним XHTML файлом; особо большие книги требуют проверки производительности. Внешние ссылки FB2 не переносятся; сложные таблицы, SVG, нестандартная разметка, всплывающие сноски и точное воспроизведение оригинального оформления не заявлены. EPUB с DRM не поддержан.

До полноценной первой версии остаются реальные обложки, загрузки в фоне и тесты на физических устройствах. Точная оценка оставшихся страниц главы не включена. Определение названия текущей главы зависит от разметки EPUB; без подходящих заголовков остаётся название раздела или «Чтение книги». Фиксированная вёрстка EPUB может ограничивать изменение шрифта и интервалов.

## Исправления 0.2.1

Фон заполняет экран с вырезом; открытие меню не меняет область чтения. Стрелки перелистывания удалены из панели, круглые кнопки и переключатели имеют округлый эффект нажатия, индикаторы переключаются без ripple. Быстрая смена типографики сохраняет якорь текста. Результаты каталога и библиотека находятся во ViewModel и переживают поворот экрана; небольшое состояние каталога сохраняется для перезапуска процесса.

Исправлены обработка глубины и якорей FB2, текст CDATA с упоминанием DOCTYPE, наследуемый xml:base и конечный адрес HTTP redirect. Импорт создаётся во временном файле; при запуске удаляются незавершённые и не внесённые в индекс результаты. Подмена батареи в smoke сбрасывается в finally. Подробные проверки и ограничения — в docs/reader-ui-verification.md.

Дополнительный сценарий: `./scripts/reader-regression.ps1` проверяет восстановление файлов, поворот поиска, область чтения и быстрые изменения размера текста. `./scripts/smoke-test.ps1 -FailAfterBatteryOverride` намеренно завершает проверку ошибкой для проверки очистки батареи.

Регрессионный сценарий также проверяет восстановление вкладки поиска, запроса и режима «Авторы» после реального завершения фонового процесса: Home → `am kill` → возврат через «Последние приложения». Скрипт подтверждает смену PID. При очистке незавершённых файлов сравниваются индекс, SHA-256 готовых книг, сохранённые позиции и существующие закладки. Исходные настройки поворота восстанавливаются в `finally`. Используйте тестовый эмулятор: сценарий открывает демо-книгу и меняет размер текста. Если ADB расположен иначе, передайте `-Adb 'C:/путь/к/platform-tools/adb.exe'`.
