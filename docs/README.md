## Как поддерживать документацию

- Меняется поведение — обнови README и соответствующий справочник.
- Меняется хранение — обнови data-storage.md и опиши совместимость старых данных.
- Меняются команды или зависимости — обнови development.md и CI.
- Принимается важное архитектурное решение — добавь короткий ADR, укажи, какое решение он заменяет.
- Закрывается ограничение или появляется подтверждённая проблема — обнови project-status.md со ссылкой на проверку.
- Новый отчёт содержит дату, проверенное состояние, команды и ограничения. Исторические результаты не переписываются как результаты текущего запуска.

Документы в `superpowers/` — обычные Markdown-файлы; название каталога не требует использования одноимённого расширения.
