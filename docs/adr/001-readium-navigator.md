# ADR 001: Readium как EPUB navigator

Статус: принято, ретроспективная запись 12 октября 2026 года.

## Контекст

Приложению нужны EPUB-навигация, оглавление, reflow, настройки текста и восстанавливаемая позиция. В исходном [дизайне](../superpowers/specs/2026-10-12-reader-design.md) выбран готовый движок. Собственный renderer потребовал бы отдельной реализации этих возможностей.

## Решение

Использовать закреплённый Readium Kotlin Toolkit 3.0.0. Publication открывается через Readium, EPUB показывает EpubNavigatorFragment. Compose-панели создаются приложением поверх navigator. Интеграция и lifecycle остаются в `app`; независимые расчёты — в `core`.

## Последствия

Нужно учитывать fragment factory, состояния Activity, insets и асинхронную переразбивку текста. Позиции хранятся в формате Readium Locator. Обновление Readium требует проверки восстановления старых Locator, viewport, типографики и фонового открытия. Нельзя по текущей документации новой версии угадывать API 3.0.0.
