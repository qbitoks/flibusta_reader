# Текущий объём и открытые ограничения

Состояние реализации 0.2.1 на 12 октября 2026 года. Это единый указатель текущих ограничений; подтверждение конкретного изменения требует нового запуска проверок.

## Реализовано

Локальная библиотека; поиск книг/авторов и OPDS-навигация; отдельные HTTPS-источники каталога и скачивания; импорт EPUB/FB2/FB2.ZIP; локальная конвертация FB2; демо-книга без сети; Readium-читалка; панели, HUD, типографика, темы, прокрутка, яркость окна; восстановление позиции и одна закладка на книгу.

## Открытые ограничения продукта

| Ограничение | Что нужно учитывать в новых задачах |
| --- | --- |
| Загрузка только в процессе приложения | Нет фонового сервиса, очереди и resume; незавершённую загрузку повторяют |
| Нет MOBI, PDF, DRM, аккаунтов и синхронизации | Это новый объём, а не существующая функция с ошибкой |
| Вместо исходных обложек — типографические карточки | Реальные обложки ещё не реализованы |
| Одна закладка на книгу | Несколько закладок потребуют новой схемы/UX |
| FB2 в одном XHTML | Крупные книги требуют проверки памяти и производительности |
| Ограниченная точность воспроизведения FB2 | Нет гарантии сложных таблиц, SVG, нестандартной разметки и всплывающих сносок; внешние FB2-ссылки не переносятся |
| EPUB fixed layout | Может ограничивать типографику; точные оставшиеся страницы главы не реализованы |
| Приватное локальное хранение | Нет пользовательского экспорта/backup; повреждённый индекс не имеет автоматической процедуры восстановления |
| Стартовая очистка и чтение библиотеки синхронны | BookRepository в onCreate и library в onCreate/onResume выполняют файловый I/O на UI thread; большая библиотека требует проверки задержек |
| Распространение release | Нужно собрать полный набор лицензий зависимостей; сейчас сохранена лицензия Readium |

## Пробелы проверки

- Физические телефоны, прошивки vivo и Android 16 не подтверждены имеющимися отчётами; эмуляторные проверки выполнялись на API 35.
- Минимально поддерживаемый API 34 требует отдельного Android smoke, если меняются platform/lifecycle-поведение.
- Полный сетевой поиск, пагинация и история после смерти процесса требуют сценария с управляемыми данными каталога.
- Реальное прерывание импорта и повреждённый индекс требуют отдельного сценария сохранности данных.
- Все разновидности EPUB/FB2, большие книги и производительность не покрыты существующим набором.
- CI проверяет JVM, сборку и lint. Для тегов/ручных запусков предусмотрены две ADB-регрессии на API 35; обычный push/PR их не выполняет. См. [release-pipeline.md](release-pipeline.md); компиляция не заменяет проверку устройства.

Не превращай этот список автоматически в разрешение реализовать все функции. Выбирай ограничение по порученной задаче. При его закрытии обнови этот документ и добавь ссылку на фактическую проверку.
