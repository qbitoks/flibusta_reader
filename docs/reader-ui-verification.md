## Исправления пользовательского ревью

| Замечание | Изменение | Проверка |
|---|---|---|
| R01 | Итеративный обход проверяет глубину FB2 до рекурсивного renderer; лимит 128 | JVM: 5000 вложенных секций возвращают обычное исключение |
| R02 | Транзакция fragment и диалог ошибки ждут RESUMED; state loss не используется | Обычный Home во время открытия и возврат через последние приложения прошли; сценарий с управляемой задержкой ещё не автоматизирован |
| R03 | Исходные id резервируются заранее; корневой start и новые section-N получают свободные id | JVM: ранний/поздний section-N и исходный start |
| R04 | xml:base наследуется от feed до конкретного link, HTTPS проверяется после разрешения | JVM: feed/entry/link, относительный next, HTTP base |
| R05 | HTTP-клиент передаёт конечный URL ответа парсеру | JVM: цепочка с другим путём и другим host; реальный HTTPS endpoint отдельно не запускался |
| R06 | Наблюдаемое состояние каталога и библиотеки во ViewModel; Bundle содержит только небольшие поля и адреса | Эмулятор: поворот запроса/режима; полный сетевой поиск с пагинацией и смертью процесса отдельно не запускался |
| R07 | Подготовка в .part, атомарная публикация EPUB, очистка неиндексированных результатов один раз при старте процесса | Эмулятор: восстановление искусственно оставленных файлов с сохранением индекса |
| R08 | Перед проверкой DTD исключаются XML-комментарии и CDATA; внешние сущности остаются отключены | JVM: обычный текст DOCTYPE разрешён, настоящая DTD запрещена |
| R09 | Подмена батареи защищена finally | Эмулятор: намеренное исключение и проверка системных обновлений |

Повторное независимое ревью выявило и помогло исправить два дополнительных случая: обновление списка книг после уничтожения Activity и пересечение переходов с отложенным восстановлением якоря. После исправления новых подтверждённых P2+ замечаний в проверенном объёме не обнаружено.

## Ограничения проверки

Используется эмулятор Android 15 (API 35), не физический vivo X300 Pro. Android 16 и прошивка vivo требуют проверки установленного APK на телефоне пользователя. Это не утверждение, что все разновидности EPUB/FB2 и все сценарии каталога проверены. Импорт глубоко вложенного FB2 проверен на JVM; отдельный Android сценарий описан в исходном ревью. MOBI, фоновые загрузки и синхронизация остаются вне текущего объёма.
