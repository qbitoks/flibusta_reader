# Reader UI Implementation Plan

**Goal:** Implement the approved immersive reader and persistent, individually hideable time/progress/battery HUD.

**Architecture:** Pure Kotlin reader options and interaction policy; app preference store; separate native overlay ComposeViews above a constant-sized Readium frame; Compose bottom sheets. System time/battery broadcasts are registered only while the activity is started.

**Tech Stack:** Existing Kotlin/Compose/Readium, Android window insets and brightness API, JUnit.

Execution is inline, as explicitly requested in this chat. The existing clean checkout is reused so delivered APK paths stay in the user's workspace.
