# Подготовка проекта для coding agents

Статус: реализовано по запросу пользователя от 12 октября 2026 года «Напиши универсальную инструкцию для любого агента. Выполни свои рекомендации». Результаты: [agent-readiness-verification.md](../../agent-readiness-verification.md).

## Цель

Новый агент без истории чатов должен найти нужный код, понять ограничения, подготовить изменение и выбрать проверку. Документация не требует Codex, плагинов, skills, MCP или конкретной модели.

## Решение

- Корневой AGENTS.md — общий контракт: назначение, маршруты чтения, инварианты, команды, порядок работы и критерии завершения.
- CLAUDE.md, GEMINI.md, .cursor/rules/project.mdc и .github/copilot-instructions.md — короткие указатели на общий контракт; правила не дублируются.
- docs/README.md разделяет текущие справочники и исторические материалы. architecture.md, development.md, data-storage.md и project-status.md описывают текущий код, проверки и открытые ограничения.
- Небольшие ADR фиксируют существующие решения: Readium, локальная конвертация FB2, хранение EPUB и Locator. Новая архитектура приложения не вводится.
- scripts/doctor.ps1 проверяет JDK, wrapper, Android SDK и при запросе тестовый эмулятор. Не устанавливает зависимости и не меняет данные приложения.
- GitHub Actions использует общий android.yml, появившийся в параллельной задаче выпуска: сборка, JVM tests, lint и сохранение пакета/отчётов; Android-регрессии доступны для тегов/ручных запусков. Дублирующий workflow не создаётся. Doctor и compileReleaseKotlin проверяются локально.

## Границы

Не менять версии зависимостей, пользовательское поведение и форматы хранения. Не переносить исторические утверждения PASS в новый отчёт без свежего запуска. Не публиковать APK, не отправлять изменения в remote и не требовать новых разрешений для уже согласованных локальных работ.

## Проверка

Сверить документацию с исходниками; проверить локальные ссылки и синтаксис PowerShell/YAML; выполнить doctor в нормальном и ошибочном окружении; выполнить build.ps1 и compileReleaseKotlin. Указать отдельно, что удалённый GitHub Actions и автоматическое чтение правил сторонними агентами локально не проверяются.
